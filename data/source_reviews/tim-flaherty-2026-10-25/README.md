# Tim Flaherty source hold

The [CMU Mathematical Sciences profile](https://www.cmu.edu/math/people/faculty/flaherty.html) identifies the faculty member and labels its publication section **Select Publications**. It lists the 1999 Flaherty–Wang article. The [publisher PDF](https://intlpress.com/site/pub/files/_fulltext/journals/ajm/1999/0003/0002/AJM-1999-0003-0002-a007.pdf) and pinned Crossref DOI record corroborate the article, author pair, journal, and date. The publisher uses “Tim Flaherty”; CMU supplies “Timothy J. Flaherty” for the same titled work.

`candidate-held.json` preserves this one verified work as **held source evidence**. CMU's selected list and a bounded Scholar profile search do not establish a full academic history or a verified Scholar account. This review assigns no Scholar ID, creates no snapshot observation, and changes neither the Hub nor either map. A future whole-researcher batch must reconcile an exhaustive CV/bibliography or a verified full Scholar profile before this candidate can enter publication output.

`manifest.json` pins the exact CMU HTML and Crossref JSON capture hashes. The CMU HTML is gzip-compressed with a fixed timestamp for a small reproducible archive.
